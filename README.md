# Archived Project

⚠️ This Symfony-based platform is no longer actively maintained.

The LakaMark platform has migrated to a new Laravel-based architecture.

The active repository is now available here:

* [LakaMark Laravel](https://github.com/Lakamark/lakamark-laravel)

This repository is preserved as an archived technical reference and historical reference for the original platform architecture.

---

## Why Was the Project Archived?

Over time, the platform evolved toward a more content-driven and application-oriented architecture where Laravel provided a workflow better aligned with the project's current goals and development philosophy.

The migration also allowed the platform to simplify frontend integration and progressively rethink parts of the application architecture.
